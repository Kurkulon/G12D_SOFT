Адрес 0x0600 (0x0700 для дубликата)

1.0 Запрос идентификации
	0x0600  	
	------		
	1. ответное слово
	2. номер прибора
	3. версия прибора

1.1 Запрос специальных параметров 
	0x0610  	
	------		
	1. ответное слово
	2. ШС усиление (0 - автоподстройка, 1..16)
	3. НЧ длина оцифровки (ushort)
	4. НЧ шаг оцифровки (ushort)
	5. ВЧ длина оцифровки (ushort)
	6. ВЧ шаг оцифровки (ushort)
	7. ШС НЧ количество окон спектра
	8. ШС ВЧ количество окон спектра

1.2 Старт измерений
	0x0620
	------
 	1. ответное слово

1.3 Запрос спектров
	0x063x (x = 0 НЧ, 1 ВЧ)
	------
 	1. ответное слово
	2. усиление текущее (0..15)
	3. количество окон спектра (ushort)
	4,5. Шаг частоты (float)
	6,7. Начальная частота (float)
	8. максимальная амплитуда волнового пакета(ushort)
	9. энергия волнового пакета(ushort)
	10. температура в приборе(short)(0.1гр)
	11. температура процессора(short)(0.1гр)
	12-?. данные (до 2048шт)

1.4 Запрос волн
	0x064x (x = 0 НЧ, 1 ВЧ)
	------
 	1. ответное слово
	2. усиление текущее (0..15)
	3. длина оцифровки (ushort)
	4. шаг оцифровки (ushort)
	6. максимальная амплитуда волнового пакета(ushort)
	7. энергия волнового пакета(ushort)
	8. температура в приборе(short)(0.1гр)
	9. температура процессора(short)(0.1гр)
	10-?. данные (до 4096шт)

---------------------------------------------------------------------
2.0 Установить параметры
	0x0680 	     	
	0xpppp: 0x1 - номер прибора, 
		0x2 - резерв
		0x3 - Изменить адрес прибора (основной 0x06 /дубликат 0x07) 

	0xdddd: данные
	------
	1. ответное слово

2.1 Установить параметры ШС
	0x0690 
	0xpppp: 0x1. ШС КУ(0 - автоподстройка, 1..16), 
		0x2. НЧ длина оцифровки (ushort) 
		0x3. НЧ шаг оцифровки (ushort) (0.01 мкс)
		0x4. ВЧ длина оцифровки (ushort)
		0x5. ВЧ шаг оцифровки (ushort) (0.01 мкс)
		0x6. ШС количество окон спектра НЧ (4..2048)
		0x7. ШС количество окон спектра ВЧ (4..2048)
	0xdddd: данные
	------	
	1. ответное слово

2.3 Сохранить все параметры в памяти прибора
	0x06F0 (поскольку запись в память медленная - ответ приходит с задержкой в несколько десятков мс)
